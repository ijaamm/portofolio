Kopi Krajan Pendopo Cilik • Fullstack

Sistem Pemesanan Menu Berbasis QR Code

Merancang dan mengembangkan secara mandiri sistem pemesanan menu berbasis QR Code untuk Kopi Krajan Pendopo Cilik menggunakan Laravel. Pelanggan cukup memindai QR Code di meja untuk melihat menu, memesan, dan membayar melalui QRIS tanpa perlu menunggu pelayan. Proyek ini mencakup seluruh tahap pengerjaan, mulai dari perancangan antarmuka di Figma, pengembangan frontend, hingga pengembangan backend, termasuk dashboard admin dan kasir untuk mengelola menu serta pesanan.

  • Halaman menu interaktif dengan filter kategori kopi, non-kopi, dan snack
  • Alur pemesanan lengkap mulai dari keranjang belanja hingga checkout
  • Pembayaran non-tunai melalui QRIS dengan integrasi payment gateway
  • Dashboard admin dan kasir untuk mengelola menu, memantau status pesanan, melihat laporan penjualan, dan mengatur stok
  • Desain responsif dengan nuansa warm tone yang selaras dengan identitas kafe

Sistem PPDB TK Aisyiyah Bustanul Athfal Banjareja

Capstone project berupa sistem Penerimaan Peserta Didik Baru (PPDB) untuk TK Aisyiyah Bustanul Athfal Banjareja, yang dikerjakan oleh tim empat orang menggunakan Laravel. Dua anggota berperan sebagai developer, sedangkan dua anggota lainnya menangani perancangan sistem dan penyusunan laporan. Sebagai Web Developer, saya bertanggung jawab atas seluruh antarmuka sistem, mulai dari halaman informasi untuk calon wali murid hingga dashboard admin.

  • Menyajikan informasi PPDB dan ringkasan kuota pendaftaran kepada calon wali murid
  • Menampilkan profil sekolah, sejarah, visi, dan misi
  • Form pendaftaran dan dashboard admin untuk mengelola data pendaftar
  • Dikembangkan bersama tim beranggotakan empat orang menggunakan Laravel
